풀이체커 수정 내용

판정 변경·사진 확대 업데이트
- 문제별 판정 배지 옆 연필 버튼에서 맞음·틀림을 직접 변경
- 별도의 수정됨 표시는 사용하지 않음
- 직접 변경한 판정을 상단 틀린 문제 수에 즉시 반영
- 분석 완료 사진을 누르면 전체 화면으로 확대
- 모바일 핀치 줌·드래그, PC 마우스 휠 줌·드래그 지원
- PC 확대 후 이동은 Windows 브라우저용 마우스 드래그 이벤트로 보강
- 바깥 영역·닫기 버튼·Esc 키로 확대 화면 종료
- Windows용 SUPER_LOCAL.bat 포함

1. 일반 사용자 화면
- 입력토큰, 출력토큰, 누적토큰을 화면과 사용자용 API 응답에서 숨김
- 상단에는 사용 장수 / 한도만 표시
- 풀이체커 사용자 화면의 글자 크기를 기존보다 10px 크게 조정

2. 관리자 화면
- 계정별 입력토큰 / 출력토큰 / 누적토큰 유지
- 계정별 누적 예상비용(USD) 추가
- 전체 입력토큰 / 전체 출력토큰 / 전체 누적 예상비용 요약 추가
- 비용은 Gemini 3.1 Pro Preview 사용량만 집계

3. 배포
- 기존 TOKEN_SPLIT_UPDATE.sql을 이미 실행했다면 Supabase SQL을 다시 실행할 필요 없음
- 이 ZIP의 프로젝트 파일을 GitHub에 덮어쓴 뒤 Netlify 재배포
- 모델 요금이 바뀌면 Netlify 환경변수에서 아래 값을 변경
  GEMINI_INPUT_PRICE_PER_1M
  GEMINI_OUTPUT_PRICE_PER_1M
V6 Pro 전용·사진 편집 업데이트

- 모든 분석: Gemini 3.1 Pro Preview, thinkingLevel LOW
- 최대 출력 토큰 2,000
- 최대 10장 업로드
- 사진 편집에 확대·축소·회전·초기화·자르기 영역·지우개 제공
- 상단에 총 분석 문제 수와 틀린 문제 수 표시
- 설명문 수식 및 sqrt/frac 손상 복구
- Pro 입력·일반 출력·추론 토큰과 비용 누적
- 관리자 전체 초기화(총 한도 유지)
- 계정 요약·분석 사용내역 Excel 다운로드
- 배포 전 MODEL_USAGE_UPDATE.sql을 Supabase SQL Editor에서 1회 실행
