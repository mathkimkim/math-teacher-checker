풀이체커 수정 내용

1. 일반 사용자 화면
- 입력토큰, 출력토큰, 누적토큰을 화면과 사용자용 API 응답에서 숨김
- 상단에는 사용 장수 / 한도만 표시
- 풀이체커 사용자 화면의 글자 크기를 기존보다 10px 크게 조정

2. 관리자 화면
- 계정별 입력토큰 / 출력토큰 / 누적토큰 유지
- 계정별 누적 예상비용(USD) 추가
- 전체 입력토큰 / 전체 출력토큰 / 전체 누적 예상비용 요약 추가
- 기본 계산 기준: Gemini 3.5 Flash 입력 $1.50/1M, 출력 $9/1M

3. 배포
- 기존 TOKEN_SPLIT_UPDATE.sql을 이미 실행했다면 Supabase SQL을 다시 실행할 필요 없음
- 이 ZIP의 프로젝트 파일을 GitHub에 덮어쓴 뒤 Netlify 재배포
- 모델 요금이 바뀌면 Netlify 환경변수에서 아래 값을 변경
  GEMINI_INPUT_PRICE_PER_1M
  GEMINI_OUTPUT_PRICE_PER_1M
